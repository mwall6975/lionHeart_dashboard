Manual Export

Run a small script yourself to export your Lionheart session history to a file, then upload it into the dashboard. You'll need your user_id first — see “How do I get my userid?” on the main page.

  1. Install Node.js 18+ if you don't have it — same installer for macOS, Windows, and Linux.
  2. Save the script below as export-lionheart.js (already in the repo as export-lionheart.js if you cloned it).
    Windows: Notepad works, but set "Save as type" to All Files — otherwise it'll save as export-lionheart.js.txt.
  3. Open a terminal in that folder and run: node export-lionheart.js YOUR_USER_ID
    macOS/Linux: Terminal — cd to the folder, then run the command.
    Windows: Command Prompt or PowerShell — cd to the folder (e.g. cd C:\Users\you\Documents), then run the same command. If node isn't recognized, close and reopen the terminal so it picks up the updated PATH.
  4. Go back to the dashboard and upload the resulting lionheart-export.json.
