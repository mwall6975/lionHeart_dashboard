How do I get my userid?
Just want to try the app first? Upload sample-lionheart-data.json (included in the repo alongside this app) — it's synthetic dummy data, no F45 account needed.

To see your own data, F45's Lionheart API is undocumented, so this takes a bit of manual work the first time:

  1. Find your personal user_id. There's no public way to look this up, but it shows up in your phone's own logs when you open the F45 app.
    Android: connect your phone via USB with adb installed, run adb logcat | grep externalId, then open the F45 app — look for a line like login(externalId: 12345678, jwtBearerToken: null). That number is your user_id.
    iPhone: the same idea works by viewing your device's console logs in Xcode's Window → Devices and Simulators while opening the app, then searching the log for externalId.
    Alternatively, intercept your phone's network traffic (e.g. with mitmproxy or HTTP Toolkit) while opening a class result, and read user_id out of the request URL to api.lionheart.f45.com.
  2. Install Node.js 18+ if you don't have it — same installer for macOS, Windows, and Linux.
  3. Save the script below as export-lionheart.js (already in the repo as export-lionheart.js if you cloned it).
    Windows: Notepad works, but set "Save as type" to All Files — otherwise it'll save as export-lionheart.js.txt.
  4. Open a terminal in that folder and run: node export-lionheart.js YOUR_USER_ID
    macOS/Linux: Terminal — cd to the folder, then run the command.
    Windows: Command Prompt or PowerShell — cd to the folder (e.g. cd C:\Users\you\Documents), then run the same command. If node isn't recognized, close and reopen the terminal so it picks up the updated PATH.
  5. Upload the resulting lionheart-export.json below.
Or: fetch directly from your F45 account (no download step)

This dashboard talks to a Cloudflare Worker that proxies F45's Lionheart API (which doesn't allow browsers to call it directly). If you were given an access token for it, enter that and your user_id (see the manual-export steps above for how to find it) below to fetch your history directly — no file to download or upload.

Want to run your own instead (e.g. you're forking this project)? The worker code and step-by-step setup are in the repo under cloudflare-worker/ — deploy it (free tier, a few minutes), then update the WORKER_URL constant near the top of this page's script to point at it.
